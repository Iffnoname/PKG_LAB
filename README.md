# Лабораторная работа 1 — Цветовые модели

**Вариант №4:** преобразования **RGB ↔ HSV ↔ LAB**.

## Что реализовано

- Десктопное GUI-приложение на **Tkinter** (модуль `ttk` для оформления).
- Одновременное отображение цвета в трёх моделях: **RGB**, **HSV**, **CIE L\*a\*b\***.
- Задание цвета **тремя способами** для каждой модели:
  1. поля точного ввода (`Entry`, подтверждение Enter или потеря фокуса);
  2. ползунки (`Scale`);
  3. стандартная палитра `colorchooser.askcolor()`.
- Автоматический пересчёт остальных моделей при изменении любой компоненты.
- Блок предпросмотра цвета и строка **HEX**.
- Статусная строка для ошибок ввода и предупреждения об **clipping**.
- Собственные функции преобразования в `color_converter.py` (без `colorsys` и сторонних color-библиотек).

## Цветовые модели и цепочки преобразований

| Направление | Реализация |
|-------------|------------|
| RGB ↔ HSV | Прямые формулы |
| RGB ↔ LAB | RGB → XYZ → LAB и LAB → XYZ → RGB |
| HSV → LAB | HSV → RGB → LAB |
| LAB → HSV | LAB → RGB → HSV |

Белый эталон для Lab: **CIE D65**. Пространство RGB: **sRGB** с гамма-коррекцией.

## Как пользоваться

1. Меняйте **R, G, B** (поля или ползунки) — обновятся HSV и LAB.
2. Меняйте **H, S, V** — пересчитаются RGB и LAB.
3. Меняйте **L, a, b** — пересчитаются RGB и HSV (возможен clipping RGB).
4. Кнопка **«Выбрать цвет»** — системная палитра Tkinter.
5. Следите за строкой **Статус:** при неверном вводе или обрезании значений.

## Диапазоны

| Модель | Компоненты | Диапазон |
|--------|------------|----------|
| RGB | R, G, B | 0 – 255 (целые) |
| HSV | H | 0 – 360° |
| HSV | S, V | 0 – 100 % |
| LAB | L | 0 – 100 |
| LAB | a, b | −128 – 127 (рабочий диапазон UI) |

HSV и LAB в интерфейсе показываются с **2 знаками** после запятой; расчёты используют полную точность `float`.

## Выход за диапазон (clipping)

При **LAB → RGB** (и **XYZ → RGB**) линейные значения могут выходить за [0, 255]. Программа:

- не завершается с ошибкой;
- выполняет **clipping** к 0…255;
- при подтверждении ввода LAB/HSV или при явном выходе за gamut показывает сообщение в статусной строке.

При движении ползунков LAB предупреждение о clipping **не** показывается на каждый шаг (чтобы не мешать).
